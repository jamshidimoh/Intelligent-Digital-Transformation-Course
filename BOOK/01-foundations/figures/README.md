# تصاویر فصل ۱

تصاویر فصل باید آموزشی و مفهوم‌محور باشند.

## قواعد

- هر تصویر باید یک مفهوم را بهتر از متن توضیح دهد.
- تصاویر تزئینی یا تکراری استفاده نشوند.
- برای نمودارهای مفهومی، ترجیح با تولید داخلی و قابل‌ویرایش است.
- برای تصاویر اقتباسی، منبع و مجوز ثبت شود.
- برای تصاویر تولیدشده با AI، برچسب «تولیدشده برای کتاب» و توضیح کوتاه ثبت شود.

## تصاویر پیشنهادی فصل ۱

1. تفاوت Digitization / Digitalization / Digital Transformation
2. مسیر تکامل از IT تا Intelligent Digital Transformation
3. مدل شش‌لایه تحول دیجیتال هوشمند
4. مقایسه سازمان سنتی، دیجیتال و AI-Native
5. مدل اجتماعی–فنی تحول دیجیتال

در نسخه نهایی، هر تصویر باید در متن فصل محل ارجاع مشخص داشته باشد.
