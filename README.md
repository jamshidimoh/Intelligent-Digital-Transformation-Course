# مبانی تحول دیجیتال هوشمند

## Intelligent Digital Transformation Course

این مخزن پروژه تألیف یک کتاب دانشگاهی و محتوای آموزشی مقطع کارشناسی ارشد با عنوان «مبانی تحول دیجیتال هوشمند» است.

### هدف

تولید یک کتاب حدود ۱۵۰ صفحه‌ای، روان و تشریحی با ساختار ۱۰ فصل که تحول دیجیتال را از منظر سازمان، استراتژی، معماری، داده، هوش مصنوعی، مدل کسب‌وکار، عملیات، انسان و حکمرانی بررسی کند.

### اصول علمی

- کتاب‌های دانشگاهی معتبر، به‌ویژه ویرایش‌ها و آثار ۲۰۲۵–۲۰۲۶، ستون اصلی توضیح و آموزش هستند.
- مقالات داوری‌شده ۲۰۲۵–۲۰۲۶ برای یافته‌های جدید و نقد علمی استفاده می‌شوند.
- استانداردهای رسمی برای حوزه‌هایی مانند AI Governance و مدیریت ریسک به‌کار می‌روند.
- گزارش‌های صنعتی فقط در مواردی که شواهد و مطالعه موردی معتبر ارائه کنند وارد محتوا می‌شوند.
- منابع قدیمی فقط برای پیشینه نظری یا تعریف مفاهیم بنیادی استفاده می‌شوند، نه به‌عنوان مبنای اصلی ادعاهای جدید.

### اصول نگارش

- هر فصل مانند یک فصل واقعی کتاب دانشگاهی نوشته می‌شود، نه خلاصه اسلاید.
- متن فارسی، آموزشی، تشریحی و روان است و اصطلاح انگلیسی مهم در نخستین کاربرد ارائه می‌شود.
- هر مفهوم مهم با توضیح، مثال، مقایسه یا نمودار آموزش داده می‌شود.
- از تصاویر و نمودارهای آموزشی در نقاطی استفاده می‌شود که به فهم کمک کنند؛ تصویر صرفاً تزئینی نیست.
- دیدگاه‌های مخالف، محدودیت‌ها و عدم‌قطعیت‌های علمی پنهان نمی‌شوند.

### ده فصل

1. مبانی و تکامل تحول دیجیتال هوشمند
2. فناوری‌های پیشران تحول دیجیتال نسل جدید
3. استراتژی تحول دیجیتال و مدل عملیاتی سازمان
4. معماری سازمانی در عصر تحول دیجیتال و AI
5. داده، Enterprise AI و سازمان هوشمند
6. مدل‌های کسب‌وکار دیجیتال و اکوسیستم‌ها
7. عملیات هوشمند، اتوماسیون و Digital Twin
8. رهبری، فرهنگ و آینده کار در عصر AI
9. حکمرانی دیجیتال، AI Governance و سازمان قابل اعتماد
10. طراحی Blueprint تحول دیجیتال هوشمند

### معماری تولید

متن هر فصل به بخش‌های کوچک Markdown تقسیم می‌شود تا محدودیت طول پیام مانع تولید کتاب نشود. فایل `tools/build_book.py` بخش‌ها را به خروجی یکپارچه تبدیل می‌کند و GitHub Actions فرایند ساخت را اجرا می‌کند.
