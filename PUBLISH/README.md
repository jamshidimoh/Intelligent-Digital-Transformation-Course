# خروجی‌های نهایی کتاب

این پوشه محل خروجی‌های مشتق‌شده کتاب است.

## اصل تولید

فایل‌های Word و PDF مستقیماً در GitHub Actions از محتوای Markdown موجود در `BOOK/` ساخته می‌شوند. فایل‌های نهایی این پوشه توسط انسان یا ChatGPT به‌صورت دستی تولید نمی‌شوند.

## ساختار

`PUBLISH/CHAPTERS/<chapter>/`

برای هر فصلِ دارای فایل `BOOK/<chapter>/.publish-enabled`، Pipeline این فایل‌ها را تولید می‌کند:

- `<chapter>.docx`
- `<chapter>.pdf`

فصل‌های فاقد نشانگر `.publish-enabled` تا زمان عبور از همه Gateهای علمی، آموزشی و fact-check وارد خروجی انتشار نمی‌شوند.

## قالب انتشار

خروجی‌ها با استاندارد RTL فارسی، متن دوزبانه، فونت‌های مناسب، حاشیه و فاصله‌گذاری استاندارد، جدول‌ها، شکل‌ها، کپشن‌ها، Header/Footer و شماره صفحه ساخته می‌شوند.

## نکته

`PUBLISH/CHAPTERS` منبع اصلی محتوا نیست. منبع اصلی در `BOOK/` است و این فایل‌ها خروجی مشتق‌شده و قابل بازتولید Pipeline هستند.
